# Confinity ♾️
*Where a question meets its code.*

Confinity is a lightweight, open marketplace connecting people who need software built with remote developers ready to ship code. No bloated agency fees, no spammy bidding wars, and no algorithm gaming—just direct, honest collaboration.

---

### 🚀 The Vision
Most freelance platforms are cluttered, noisy, and charge heavy platform fees just to talk to a developer. Confinity is built to close the loop:

* **For Clients:** Post what you need in plain English, set a realistic budget, and get responses from real developers.
* **For Developers:** Browse open projects, highlight your actual stack, and keep 100% of what you earn.
* **Zero Platform Fees:** Kept 100% free while building out the core features and proving the platform's value.

---

### 🚧 Current Status: Active Development (`v0.1`)
Confinity is actively being built in the open. 

* **Auth:** Google OAuth integrated via Firebase[cite: 1].
* **Frontend:** Clean, modern dark UI built with static HTML, CSS, and modular JS.
* **Backend In Progress:** Firestore integration for posting and querying active projects.

### 🛠️ Tech Stack
* **Frontend:** Semantic HTML5, CSS3 (Custom Variables, CSS Grid/Flexbox), Native JavaScript ES Modules
* **Auth & Database:** Firebase Authentication (Google Auth), Cloud Firestore
* **Hosting:** GitHub Pages
