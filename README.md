# Confinity ♾️
*Where a question meets its code.*

Confinity is a lightweight, open marketplace connecting people who need software built with remote developers ready to ship code[cite: 3]. No bloated agency fees, no spammy bidding wars, and no algorithm gaming—just direct, honest collaboration[cite: 3].

---

### 🚀 The Vision
Most freelance platforms are cluttered, noisy, and charge heavy platform fees just to talk to a developer. Confinity is built to close the loop:

* **For Clients:** Post what you need in plain English, set a realistic budget, and get responses from real developers[cite: 3, 4].
* **For Developers:** Browse open projects, highlight your actual stack, and keep 100% of what you earn[cite: 3, 4].
* **Zero Platform Fees:** Kept 100% free while building out the core features and proving the platform's value[cite: 3].

---

### 🚧 Current Status: Active Development (`v0.1`)
Confinity is actively being built in the open[cite: 2, 3]. 

* **Auth:** Google OAuth integrated via Firebase[cite: 1].
* **Frontend:** Clean, modern dark UI built with static HTML, CSS, and modular JS[cite: 1, 2, 3, 4].
* **Backend In Progress:** Firestore integration for posting and querying active projects[cite: 1].
